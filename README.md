# Traffic Sign Recognition using CNN

## Overview

This project implements a Convolutional Neural Network (CNN) for automatic traffic sign classification using the German Traffic Sign Recognition Benchmark (GTSRB) dataset.

## Features

- Traffic sign image classification
- Image preprocessing and normalization
- CNN-based deep learning model
- Model training and evaluation
- Prediction on unseen traffic sign images

## Technologies

- Python
- TensorFlow
- Keras
- OpenCV
- NumPy
- Pandas
- Matplotlib

## Dataset

GTSRB (German Traffic Sign Recognition Benchmark)

## Results

- Training Accuracy: 98%
- Validation Accuracy: 95%
